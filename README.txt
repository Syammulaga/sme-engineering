# SME Engineering & Design — Free Website

## Files
- `index.html` — complete one-page website
- `style.css` — responsive design
- `script.js` — mobile menu, year and enquiry email function

## Run it
Double-click `index.html` to preview it in your browser.

## Before publishing
1. Open `script.js`.
2. Replace `your-email@example.com` with your real business email.
3. In `index.html`, replace the placeholder WhatsApp number and email.
4. Replace portfolio placeholders with your own non-confidential project images.
5. Do not upload confidential PDO/OQEP/client drawings, project numbers, client names or proprietary documents without permission.

## Free publishing
You can publish these files for free using GitHub Pages or Cloudflare Pages. You can later buy a custom domain when the business starts generating income.
